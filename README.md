# kcal

A degree planner for Krea University students. Pick your batch, major, and minor or concentration, and kcal lays out your whole degree trimester by trimester. It shows what's required, what's left, and where each course fits.

## Why I made it

At Krea you build your own degree out of a major, maybe a minor, the core and electives, spread over nine to twelve trimesters. Most of us plan it with handbooks, spreadsheets, timetable screenshots and asking seniors. None of that checks your plan while you're making it. So you find out a course doesn't run that trimester, or that you skipped a prerequisite, at registration or, worse, in final year.

kcal checks the plan as you build it, using the university's own course list, timetables and programme rules: prerequisites, when courses are offered, credit loads and total credits. Problems show up as plain hints right on the plan.

The catalogue, requirements and offering data are scraped from the university's own programme pages and term timetables, not hand-typed, so the plan reflects what's really on offer.

## Running it

```bash
npm install
npm run dev
```
